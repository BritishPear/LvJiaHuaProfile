# Lambert 个人网站

这是可搬运的静态网站源码。入口为 `index.html`，资源保存在 `assets/`，均使用相对路径。

可直接用浏览器打开 `index.html`，也可在本目录启动静态文件服务器，例如 `python -m http.server 8000`，再访问 `http://localhost:8000`。

完整项目 ZIP 包含三段原视频。通过 Git 克隆源码时，需从 Release `website-v1` 下载 `lambert-portfolio.zip`，并将其中的 `lambert-portfolio/assets/videos/ama.mp4` 提取到本地仓库的 `assets/videos/ama.mp4`。也可直接解压完整 ZIP 后运行。

详细说明见 [WEBSITE.md](WEBSITE.md)。本说明不表示已启用在线网站托管。
